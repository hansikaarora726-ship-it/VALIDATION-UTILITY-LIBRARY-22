## About the Project
This project is a simple validation utility application built using JavaScript guard clauses.

It validates user details such as name, age, email, and password before accepting the form.

## Features
- Name validation
- Age validation
- Email validation
- Password validation
- Guard clauses to handle invalid inputs
- Displays error messages
- Shows success message when all details are valid

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
- 22-validation-utility-library.html – Contains HTML, CSS, and JavaScript in a single file.
- README.md – Project documentation.

## How to Run
1. Open the HTML file in VS Code.
2. Run it using Live Server.
3. Enter your name, age, email, and password.
4. Click the Validate Details button.
5. Check the validation results.

## Learning Outcome
Understand guard clauses and learn how to validate user input using reusable JavaScript functions.
